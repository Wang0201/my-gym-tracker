# 📱 项目介绍


Muscle Journey V3 是一个基于 Web 技术开发的个人健身成长 App。


设计目标：

> 通过记录、反馈、等级、成就系统，让自己真正坚持长期健身。



适合：

- 增肌训练者
- 居家训练
- 出差人群
- 需要长期记录习惯的人

# 🏋️ 训练模式


## 工作日（出差）


无需器械：

- 俯卧撑
- 深蹲
- 核心训练
- 徒手力量训练



## 周末（家庭）


设备：

- 10kg哑铃一对


主要训练：

- 哑铃卧推
- 单臂划船
- 肩推
- 深蹲
- 弯举
- 侧平举

# ✨ 功能


## 🏋 训练系统


- 训练打卡
- XP奖励
- 等级成长
- 连续训练记录



## ⚖️ 体重管理


- 每日体重记录
- 增重进度
- 目标完成率



## 🍚 营养系统


目标：

每日：

- 2800 kcal
- 130g 蛋白质



## 🏆 成就系统


包含：

- 首次训练
- 连续训练
- 训练次数
- 体重突破
- 最终75kg目标



## 📱 PWA支持


支持：

- 手机安装
- 离线使用
- 桌面图标
